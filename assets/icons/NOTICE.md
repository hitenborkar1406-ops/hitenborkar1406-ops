# Icon sources

Vendored so the cards render without any CDN or network access.

- `brands/` github, linux, leetcode: [Simple Icons](https://github.com/simple-icons/simple-icons) (CC0)
- `lucide/`: [Lucide](https://github.com/lucide-icons/lucide) (ISC)
